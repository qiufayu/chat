## 环境调整和数据范围

第一次通过真实接口注册时，发现 Redis 的 `chat:user:reg:id=1000000001`，低于数据库中已有账号最大值 `1000002003`，触发账号唯一索引冲突并返回500。测试前已用Lua原子地将该序号向上对齐到数据库最大值；没有下调序号或修改已有用户。消息编号计数器也核对过，与数据库及Outbox的最大消息ID一致，无需调整。

本次对齐属于运行环境数据修复；如果以后清空Redis，需要重新核对持久数据对应的编号序列，当前注册实现不会自动从MySQL修复丢失的Redis计数器。

排查阶段另创建了专用测试账号2008～2010及一条消息386662（会话1448），这些记录也保留；其好友关系已解除。已有其他账号、好友关系和历史消息未被测试脚本修改。
