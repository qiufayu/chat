# 2026-11-12 工作日志

## 接口文档梳理（ChatSystem）
- 全面梳理 `ChatSystem` 代码，识别全部 HTTP 接口（chat-user/friend、chat-group、chat-message 的 /msg /conversation /outbox /sync 控制器）与 WebSocket 接口（chat-connection Netty，入口 `/ws`）。
- 产出文档：`docs/接口文档.md`，含接口路径/方法/功能/请求与响应参数、WebSocket 帧格式、鉴权说明。
- 鉴权模型：网关 `AuthGlobalFilter` 全局 JWT 鉴权，白名单为 `/user/login`、`/user/register`、`/user/refresh`；调用方需带 `authorization`（JWT，无 Bearer 前缀）+ `device-id`（≤64）；网关注入 `user-info` 给下游；WS 握手需 `authorization`+`device-id`，缺失则关连接。
- 注意：网关当前仅路由 `/user/**`、`/friend/**`、`/group/**`、`/sync/**`、`/ws/**`，`/msg`、`/conversation`、`/outbox` 未配置网关路由（消息服务直连 8083 或 Feign 内部调用）。
